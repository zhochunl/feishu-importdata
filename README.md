# 飞书多维表格数据导入边栏插件

在浏览器里选择一个 SAS 导出的 zip 数据包，解析其中的 XML，把每个数据集写入多维表格中同名的数据表。纯前端插件，不需要后端服务，也不需要额外挂 nginx —— 构建产物 `dist/` 由飞书平台自行托管。

## 使用流程

1. 在多维表格「边栏」里添加/打开本插件。
2. 填入解压密码（SAS 下发的包是 ZipCrypto 加密的），选择 `.zip` 文件。
3. 插件解压并扫描包内每个 XML，列出「数据集名 / 行数 / 列数 / 体积」，可勾选部分域。
4. 点「开始导入」，逐域建表 → 补字段 → 分批写记录；日志区实时显示进度，可随时中止。

## 数据映射规则

- 数据表名 = XML 里 `<TABLE>` 下的记录标签名（即 SAS 数据集名，如 `LAB`），已存在同名表则复用。
- 字段名 = 记录的子元素标签名；缺失的字段用 `addField` 补齐，已有字段不动。
- 列类型（可用「自动识别数值/日期列」关闭，全部按文本写入）：
  - 整列都是数字且没有前导 0 → 数字
  - 整列都是 `YYYY-MM-DD` / ISO 日期 → 日期
  - 其余 → 文本（避免把 `"01"` 这类编码写成 `1`）
- `missing="."`、空白填充、自闭合标签 → 空值。

## 技术栈

- Vite + React 18 + TypeScript + `@lark-base-open/js-sdk`
- `@zip.js/zip.js` 负责浏览器端 ZipCrypto 解密（JSZip 不支持加密包）
- 自研深度感知 XML 解析器（`src/lib/sas_xml.ts`）：数据集标签可能与列标签同名，不能用 DOM/正则简单切分

## 目录结构

```
importdata/
├── src/
│   ├── App.tsx                 # 边栏界面：选包、勾选域、进度、日志
│   ├── main.tsx
│   ├── index.css
│   └── lib/
│       ├── sas_xml.ts          # XML 分词 + 列统计 + 类型推断（流式游标）
│       ├── zip_domains.ts      # 浏览器端解压，逐域按需读取，避免整包常驻内存
│       └── bitable_writer.ts   # 建表 / 补字段 / 分批写记录（addRecords 上限 200）
├── index.html
├── package.json
└── vite.config.ts
```

## 本地开发

```bash
npm install
npm run dev        # vite dev server，端口见 vite.config.ts
npm run build      # 产物在 dist/
```

脱离飞书环境直接打开页面时，顶部会提示「当前不在多维表格环境中」，此时只能预览界面与解析数据，无法写入。

## 飞书插件配置

1. `npm run build`
2. 在多维表格「扩展程序 → 边栏」创建自定义插件，把构建产物交给飞书平台托管（或填入自己的 HTTPS 地址）
3. 保存后在边栏打开

## 注意事项

- 单表行数受多维表格版本限制（基础版/商业标准版 2000 行，商业专业版 2 万行，商业旗舰版/企业版 5 万行）。数据集中的 `LAB`（约 2.1 万行）在低版本下会写满溢出。基础版/商业标准版可额外免费领取 1.8 万行权益；超过上限后该数据表无法再新增记录。
- 明文 XML 最大的一域约 67MB，解析按 200 行一批流式消费，但整域文本仍会一次性解出，极宽表请留意浏览器内存。
- 写入是幂等建表、非幂等写记录：重复导入同一包会追加记录，不会去重。
